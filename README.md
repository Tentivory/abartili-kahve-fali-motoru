# Abartılı Kahve Falı Motoru

## Bu Proje Nedir?

Bu, insanlık tarihinin en büyük icadıdır. Kahve fincanınızın dibindeki o anlamsız şekilleri alır, onları analiz eder ve size hayatınızın ne kadar umutsuz olduğunu bilimsel kesinlikte söyler.

**Uyarı:** Bu programı çalıştırdıktan sonra depresyona girerseniz sorumluluk kabul etmiyoruz. Sorumluluk tamamen fincanınızda.

## Nasıl Kullanılır?

```bash
python kahve_fali.py
```

Sonra fincanınızda gördüğünüz şekli yazın. Motor, yıllar süren (aslında 3 saniye) derin meditasyon sonucu falınızı açıklar.

## Özellikler

- %100 doğruluk oranı (hiçbir şey doğru değil)
- Karamsarlık seviyesi: Maksimum
- Motivasyon: Sıfır
- Çalışma garantisi: Hayır

## Lisans

Bu proje "Ne istersen yap, zaten umutsuz" lisansı altındadır.
